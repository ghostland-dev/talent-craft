# Talent Craft

Recruitment platform for candidates and recruiters.

## Features

- Candidate dashboard
- Recruiter dashboard

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/talent-craft.git
cd talent-craft
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
